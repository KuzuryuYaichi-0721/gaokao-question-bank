# Open Question Data

This directory contains only data that can be redistributed.

## gaokao-bench-2016-2022.json

- 2,996 questions
- 2016–2022
- nine subjects
- Source: OpenLMLab/GAOKAO-Bench
- License: Apache-2.0
- Normalized fields: `id`, `subject`, `region`, `year`, `exam_era`, `type`,
  `q_no`, `stem`, `options`, `answer`, `explanation`, `material`, `source`,
  `source_url`, `license`

`manifest.json` records the count, subject distribution, SHA-256, and excluded
sources.

## Not included

- 2023–2024 Updates (upstream has no declared license)
- Xiaohongshu 2025 notes or OCR
- Synthetic demo seed
- Images, PDFs, audio, databases, progress
