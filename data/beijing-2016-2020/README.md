## 概览

- **10726 道题**，来自 **770 个已收集/部分收集的试卷槽位**。
- 覆盖 2016–2020 年北京高考、一模、二模；科目包括语文、数学、英语、物理、化学、
  生物、政治、历史、地理及文综/理综。
- 文本层提取 **9670** 道，扫描件 OCR 识别 **1056** 道。
- 槽位覆盖：1384 个 = 已收集 768 + 仅答案 2 + 缺失 614。
- 不含 PDF、图片、答题卡扫描件、答案扫描件或本地缓存。

## 文件

| 文件 | 说明 |
|---|---|
| `questions.json` | 题目列表，字段与 `data/open` 基本一致，另有来源和提取元数据 |
| `papers.json` | 已收集/部分收集的试卷槽位、状态、页数、来源 URL、PDF SHA-256 |
| `coverage.json` | 完整槽位清单（含 614 个 missing），不含本地文件路径 |

## 题目字段

| 字段 | 说明 |
|---|---|
| `id` | 题目 ID，基于 paper_key + 题号 + 题干前缀生成，稳定且唯一 |
| `paper_key` | 试卷标识，如 `bj-2019-一模-海淀-数学（理）` |
| `paper_title` | 规范化试卷标题 |
| `subject` / `region` / `district` | 科目、地区、区县 |
| `year` / `month` / `exam_type` / `exam_era` | 年份、月份、一模/二模/高考、新旧高考 |
| `type` / `q_no` / `section` | 题型、题号、英语分节 |
| `stem` | 题干；扫描件和英语填空题可能是上下文窗口 |
| `options` | `{"key": "A", "text": "..."}` 列表；无选项时为空 |
| `answer` / `explanation` | 答案、解析；未提取到时为空字符串 |
| `answer_verified` | 选择题答案是否为已解析选项的键；主观题/无选项时为是否有答案 |
| `score` / `material` | 分值、材料（当前材料通常为空） |
| `source` / `source_url` | 来源站点、来源文章页 |
| `license` | 固定为 `unknown` |
| `paper_sha256` | 原始 PDF 的 SHA-256，便于核对来源 |
| `extract_method` | `text` 或 `ocr` |
| `quality` | `text` / `ocr` / `text-garbled`（数学公式等文本层缺失） |
| `needs_image` | 题干含“如图/图中/表格”或过短，脱离原图可能不完整 |
| `content_hash` | 题干 + 选项的 SHA-256，可用于跨卷去重 |

## 提取方法

1. 从 gaokzx.com、eekaotong.com、zizzs.com 等公开网页及早期本地收集下载 PDF；
   逐文件校验 SHA-256、页数和可打开性。
2. 有文本层的 PDF 用 PyMuPDF 提取；扫描件在 120 DPI 下用 RapidOCR 识别。
3. 用题号模式切分题目，识别 A–D/A–G 选项；从“参考答案”、题号-答案表、
   `【答案】`/`【解析】` 等位置回填答案。
4. 英语按“单项填空/语法填空、完形填空、阅读理解、七选五”分节解析；填空类题目
   保存为带 `____` 的上下文窗口。
5. 清洗页眉页脚、水印、答案键行和表格碎片，按 `paper_key` + 题型 + 题号去重；
   综合题从 1 重新编号的试卷会保留选择题和非选择题两个分节。

## 质量与限制

- **扫描件 OCR**：1056 道题来自 OCR，可能存在数字、公式、上下标和英文拼写错误；
  这些记录标记为 `extract_method: "ocr"`。
- **文本层公式**：部分数学/物理 PDF 的文本层丢失符号（如分式、根号、上下标），
  题干会出现 `f x x . ..` 一类片段；这些记录标记为 `quality: "text-garbled"`。
- **图片题**：1689 道题含“如图/图中/表格”或题干过短，
  原始图形未包含在 JSON 中，单独使用题干可能不完整。
- **答案覆盖**：主观题和部分扫描卷未提取到答案/解析，`answer`/`explanation` 为空。
- **来源缺失**：187 条题目/试卷没有记录来源 URL
  （早期本地收集或来源页未保存）；这些记录仍标记为 `license: unknown`，使用前请自行核对。
- **选项缺失**：261 道题的选项键不连续（如只有 A、B、D），
  可能由文本层或 OCR 漏识别造成；不要直接用于自动判分。
- **未完成扫描件**：143 个槽位只有扫描件、尚未完成 OCR，
  因此本版本不包含其题目；这些槽位仍列在 `coverage.json` 中。
- **缺失槽位**：614 个区县-科目槽位在公开来源中未找到；另有
  2 个槽位只有答案。详见 `coverage.json`。
- **英语填空**：完形填空/七选五/语法填空的 `stem` 是原文上下文窗口，不是完整题干；
  `options` 和 `answer` 可用于评测，但展示时建议同时给出原文。
- 本目录只包含文本，不包含原 PDF 和图片；如需要图形，请按 `paper_sha256` 和
  `source_url` 回溯原始文件。
